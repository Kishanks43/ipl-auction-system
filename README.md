# 🏏 IPL Auction System

A full-stack web application simulating IPL-style player auctions with bidding logic, team budgets, and real-time decision flow.
---

## 🚀 Features
- Real-time or dynamic bidding system
- Budget constraints for each team
- Player allocation logic
- Full-stack architecture (React + Node.js)
- Data-driven auction simulation

---

## 🛠 Tech Stack
- Frontend: React
- Backend: Node.js, Express
- Database: JSON

---

## 📂 Project Structure
client/ → React frontend  
server/ → Backend API  

---

## ⚙️ How to Run

### Backend
cd server  
npm install  
node server.js  

### Frontend
cd client  
npm install  
npm start  

---

## 🧠 Key Learnings
- Designing auction logic with constraints
- Managing state across multiple components
- Backend API design and data handling
